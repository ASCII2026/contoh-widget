# 📚 Pusat Navigasi Tutorial Widget & Badges (Informatika Unmul)

Halo teman-teman praktikan dan asisten lab Informatika Unmul! 👋

Selamat datang di direktori **Tutorial**. Di sini kamu bisa mempelajari panduan detail cara mengintegrasikan widget SVG dinamis, live presence Discord, dan badges dari portal [ASCII IF](https://ascii.web.id) ke repositori tugas praktikum maupun profil GitHub kamu.

---

## 🧭 Daftar Modul Tutorial

Pilih topik yang ingin kamu pelajari:

```
tutorial/
├── 📚 tutor-bimbingan-project/   -> Panduan Tracking Progres Bimbingan Tubes & Kelompok
├── 👤 tutor-widget-profil/        -> Panduan Kartu Profil Mahasiswa & Aslab (4 Tema Warna)
├── 🎮 tutor-widget-discord/       -> Panduan Live Presence Discord, Spotify & Activity
└── 🛡️ tutor-badge-shields/        -> Panduan Koleksi Badge Shields (Status, Role, Kelas, ACC)
```

---

### 1. [📚 Tutorial Bimbingan per Project](./tutor-bimbingan-project/README.md)
- **Topik**: Cara memantau tahapan bimbingan praktikum (Pra-Konsul, Konsul 1, Konsul 2, ACC Final) secara otomatis.
- **Fitur**: Mendukung **Dedicated Project ID** (`/api/widget/{groupId}.svg?type=bimbingan`) untuk menampilkan judul tubes, nama kelompok, mata kuliah, dan nama aslab pembimbing.
- **Link Modul**: 👉 [Buka Tutorial Bimbingan](./tutor-bimbingan-project/README.md)

---

### 2. [👤 Tutorial Widget Kartu Profil](./tutor-widget-profil/README.md)
- **Topik**: Memajang kartu identitas resmi lab di profil GitHub (`username/username`).
- **Fitur**: Informasi lengkap mahasiswa/aslab, angkatan, kelas, total showcase, dan 4 pilihan tema warna (`burgundy`, `dark`, `matrix`, `light`).
- **Link Modul**: 👉 [Buka Tutorial Kartu Profil](./tutor-widget-profil/README.md)

---

### 3. [🎮 Tutorial Widget Discord Live Activity](./tutor-widget-discord/README.md)
- **Topik**: Menampilkan status online Discord secara real-time, lagu Spotify yang sedang diputar, aktivitas coding di VS Code, dan role server.
- **Fitur**: Dukungan avatar global vs server guild.
- **Link Modul**: 👉 [Buka Tutorial Widget Discord](./tutor-widget-discord/README.md)

---

### 4. [🛡️ Tutorial Koleksi Badge Shields](./tutor-badge-shields/README.md)
- **Topik**: Kumpulan badge horizontal kompak untuk disematkan di header bar repositori tugas atau profil.
- **Fitur**: Badge `status` (Verified), `role` (Praktikan/Aslab), `kelas`, `bimbingan` (ACC Final), dan `projects`.
- **Link Modul**: 👉 [Buka Tutorial Badge Shields](./tutor-badge-shields/README.md)
