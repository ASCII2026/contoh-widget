## 📖 Tentang Proyek

**SIMLAB** adalah aplikasi web manajemen inventaris perangkat keras dan sistem peminjaman fasilitas laboratorium komputer Informatika Unmul. Aplikasi ini memungkinkan mahasiswa meminjam perangkat (seperti mikrokontroler Arduino, Raspberry Pi, kabel LAN, router, dan VR headset) serta mempermudah aslab dalam memantau ketersediaan stok barang secara real-time.

### ✨ Fitur Unggulan:
- 📋 **Katalog Inventaris Interaktif**: Pencarian dan filter perangkat lab berdasarkan kategori & status ketersediaan.
- 📝 **Pengajuan Peminjaman Real-time**: Form peminjaman alat dengan validasi tanggal dan NIM mahasiswa.
- 📊 **Statistik & Monitoring Stok**: Dashboard visual stok barang yang sedang dipinjam vs tersedia.
- ⚡ **Desain Modern & Responsif**: UI clean bertema dark mode dengan aksen burgundy elegan.

## 🚀 Cara Menjalankan Aplikasi di Komputer Lokal

Proyek ini dibuat menggunakan standar web modern tanpa dependensi build yang rumit. Kamu bisa langsung menjalankannya:

### Opsi 1: Langsung Buka di Browser
Cukup klik ganda (*double-click*) file [`index.html`](./index.html) pada file explorer komputermu.

### Opsi 2: Menggunakan Live Server / Local HTTP Server
```bash
# Masuk ke folder proyek
cd studi-kasus/tubes-kelompok-simlab

# Jalankan server lokal sederhana (pilih salah satu)
# Menggunakan npx serve:
npx serve .

# Atau menggunakan Python:
python -m http.server 3000
```
Buka browser di `http://localhost:3000`.
